# AP/2717 — Cinematic engineering profile

- README.md — profile and accessible text
- assets/hero.gif — original supplied six-frame cinematic animation
- assets/hero-motion.webp — 48-frame optimized loop (~24 fps)
- scripts/optimize_hero.py — optional Pillow-based offline motion build
- assets/hero-still.jpg — reduced-motion fallback
- assets/ — twelve locally generated SVG modules, plus two contribution snake SVGs produced by the workflow
- data/profile.json — curated project identity and source links
- data/contributions.json — real weekly contribution snapshot
- scripts/cinema.py — native SVG renderers for projects, skills, current focus and activity
- scripts/build_profile.py — standard-library renderer and GitHub GraphQL client
- scripts/test_build_profile.py — validation
- .github/workflows/profile-telemetry.yml — six-hour refresh and PR validation

Run `python3 scripts/build_profile.py` to rebuild the native SVG modules locally.
Run `python3 -m unittest discover -s scripts -p 'test_*.py'` to test.
Use `--live` and GH_TOKEN for fresh contribution data.
The pinned Platane/snk action generates the snake from the real GitHub daily calendar, with standard GitHub green blocks. The action and the locally rendered contribution totals are updated in one commit. A failed generation leaves the previous published files intact. The original GIF, optimized WebP and static fallback are not regenerated by the workflow. Run python3 scripts/optimize_hero.py with Pillow installed to rebuild the WebP.
